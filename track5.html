Track #5: WorldNav — World Model Navigation

Language-Conditioned Open-Loop Navigation in Continuous 3D Environments

🚀 Submit on CodaBench

👋 Welcome to Track #5: WorldNav — World Model Navigation of the RoboWorld Challenge 2026!

This track studies language-conditioned open-loop visual navigation. An agent receives a single initial egocentric observation together with a natural-language instruction, and must predict the complete trajectory that reaches the described destination. There are no goal images, no maps, and no intermediate environmental feedback: the whole action sequence has to be committed in advance.

The track is built on the LCVN benchmark and scores the planning output only. World-model-based agents, vision-language models (VLMs), vision-language-action (VLA) models and policy-only planners are all welcome — imagination quality is not part of the official ranking, so every method competes on the same footing.

Kindly refer to the LCVN repository for more technical details on this track.

🏆 Prize Pool: $1,500 for the 1st place, $800 for the 2nd place and $500 for the 3rd place (per track).

🎯 Objective

Open-loop navigation removes the comfort of re-planning: the agent sees one frame, reads one instruction, and then has to say where it will go. This stresses exactly what world models are for — anticipating how a scene unfolds from language and a single glimpse of it.

Participants are expected to:

  • Ground language from a single frame: infer the intended destination from instructions that may be concise, intricate (objects, people, scene layout) or landmark-grounded.
  • Predict a full action sequence: output the ordered relative motion commands [dx, dy, dyaw] that carry the agent from the initial pose to the goal, one command per environment step.
  • Model the world if it helps: anticipate future states and dynamics, then plan with that anticipation. World-model agents are explicitly encouraged, but the official evaluation only looks at the predicted trajectory.

Phase #1: Validation

Participants receive the released validation inputs (initial observation, instruction and number of steps per episode) for the val_seen and val_unseen splits, and submit one ZIP archive containing val_seen.json and val_unseen.json. The val_unseen Score determines the Phase 1 ranking; val_seen metrics stay visible on the leaderboard for diagnosis.

Phase #2: Final Evaluation

The withheld test inference inputs are released at the start of Phase 2. Participants submit one ZIP archive containing test.json; the test ground truth is never released and is used exclusively for the official evaluation. The test Score determines the final ranking and the awards.

Requirements

  • One ZIP archive per phase, with the JSON files at the archive root (no nested folders, no extra files).
  • Every expected episode covered exactly once, with exactly the number of steps given in the inference bundle.
  • Actions expressed in the LCVN action representation: relative motion commands [dx, dy, dyaw] in metres and radians.
  • No participant code is executed during scoring; submissions are replayed offline by the official evaluation harness.

📦 Dataset & Submission Format

Track 5 uses the LCVN dataset, released on Hugging Face at fly1113/LCVN: 39,016 trajectories and 117,048 human-verified instructions, with three instruction styles (Concise, Intricate, Landmark-grounded). Training and in-domain evaluation use Go Stanford, ReCon, SCAND and HuRoN; TartanDrive is reserved for unseen-environment evaluation. Each trajectory provides egocentric RGB frames plus traj_data.pkl with position, yaw, delta and instruction.

The train, val_seen and val_unseen splits are public; the official test split is withheld. Phase 1 submissions follow the same schema as Phase 2, so participants can validate their complete pipeline before the final evaluation.

Each split file is a JSON object with this structure:

{
  "format_version": 1,
  "split": "val_unseen",
  "episodes": [
    {
      "episode_id": "tartan_drive_0001",
      "actions": [[0.25, 0.0, 0.0], [0.0, 0.0, 0.15], [0.12, -0.05, 0.0]]
    }
  ]
}
  • actions is the ordered list of relative motion commands [dx, dy, dyaw] (metres, metres, radians), one command per environment step.
  • Episode identifiers must be unique and must cover every expected episode exactly once; the number of actions must equal the num_steps of that episode.
  • Accepted per-step bounds: |dx|, |dy| <= 2.46 m and |dyaw| <= 6.29 rad.

📏 Evaluation Metrics & Score

Metric Direction Definition
SR (Success Rate) higher is better Fraction of episodes whose final predicted position lies within the average ground-truth step length of the goal position.
ATE (Absolute Trajectory Error) lower is better RMSE of the absolute translation error between the predicted and the ground-truth trajectory (no alignment), in metres.
RPE (Relative Pose Error) lower is better RMSE of the relative translation error over consecutive steps (delta of one step), in metres.

The composite Score is identical for Track 2 and Track 5 of RoboWorld 2026:

Score = 100 * (0.70 * SR + 0.20 / (1 + ATE) + 0.10 / (1 + RPE))

Scores are computed from full-precision aggregate metrics, without rounding intermediate values, and are displayed with six decimal places. Ties are broken by higher SR, then lower ATE, then lower RPE, then earlier submission time.

🛠️ Baseline Models

Two model families from the LCVN project serve as reference baselines for this track:

  • LCVN-WM + LCVN-AC: a diffusion-based world model built on a language-conditioned diffusion transformer backbone that imagines future visual states, combined with a latent-space actor-critic agent trained with intrinsic rollout rewards.
  • LCVN-Uni: an autoregressive multimodal agent that predicts actions and future observations in a single forward pass.

Data preparation, training and evaluation commands for both families are documented in the LCVN repository. Organizer baseline results for the official metrics will be published with the Phase 1 starting kit.

❓ Frequently Asked Questions

Here, we provide a list of Frequently Asked Questions (FAQs) below for better clarity. If you have additional questions on the details about this competition, please reach out at roboworld2026@outlook.com.

What exactly do I need to submit?

One ZIP archive per phase containing the predicted action sequences: val_seen.json and val_unseen.json in Phase 1, test.json in Phase 2. No agent code, simulator or environment is required.

Do I have to run a simulator?

No. The organizers replay the submitted action sequences against the held-out ground-truth trajectories in an offline harness — nothing of yours is executed during scoring.

Do I need to be a world-model method?

No. World-model agents, VLMs, VLA models and policy-only planners are all welcome. Only the predicted trajectory is scored, so imagination quality neither helps nor hurts your ranking.

Which split decides the Phase 1 ranking?

The val_unseen Score. val_seen metrics remain visible on the leaderboard for diagnosis. Phase 2 is ranked by the withheld test Score, which determines the awards.

Where do I download the data?

From the Hugging Face release at fly1113/LCVN, or with bash download_data.sh from the LCVN repository, which fetches and extracts the released splits.

Is the test ground truth public?

No. Phase 2 releases only the test inference inputs (initial frame, instruction and number of steps); the test ground truth is used exclusively for the official evaluation.

How is the final score computed?

Score = 100 * (0.70 * SR + 0.20 / (1 + ATE) + 0.10 / (1 + RPE)), computed from full-precision metrics and displayed with six decimal places.

How long does evaluation take?

Scoring is fully offline and fast: a complete Phase 1 archive is scored in well under a minute once the submission has been processed by CodaBench.
